# 📊 Philippine Data Analyst Job Market Analysis
### Scraped from OnlineJobs.ph

---

## 📌 Overview

This project investigates the **Philippine Data Analyst job market** by scraping 200 job postings from [OnlineJobs.ph](https://www.onlinejobs.ph/) and performing exploratory data analysis (EDA) on the results. The goal is to uncover what skills, qualifications, and responsibilities employers most commonly require — and how salary varies across job types and work hours.

---

## ❓ Questions This Analysis Tries to Answer

- What are the most in-demand **skills** for Data Analyst roles in the Philippines?
- What **qualifications** do employers most frequently require?
- How does **salary** differ across job types and work hours?
- What **responsibilities** are most commonly expected of a Data Analyst?

## ⚙️ How It Works

### Step 1 — Scraping (`webScraper.py`)
Uses **Selenium** to search OnlineJobs.ph for "data analyst" and scrapes 200 job postings across multiple pages. For each posting it extracts:
- Job Title, Job Type, Salary, Hours, Date, Description, and Link

### Step 2 — Cleaning & Parsing (`jobScript.ipynb`)
The raw `Description` column is parsed using manually reviewed keyword lists for:
- **Skills** (e.g. SQL, Python, Excel, Power BI)
- **Qualifications** (e.g. bachelor's degree, experience, certifications)
- **Responsibilities** (e.g. analyze, report, dashboard, forecast)

Each column is then exploded into its own **derived/subset table** for focused analysis.

### Step 3 — EDA & Presentation (`streamlitWeb.py`)
A Streamlit web app presents the full analysis pipeline — from raw data to parsed tables to charts — with key observations written after each visualization.

## 🚀 How to Run

**Run the scraper:**
```bash
python webScraper.py
```

**Run the Streamlit report:**
```bash
streamlit run streamlitWeb.py
```

> Make sure all CSV files are in the same directory as `streamlitWeb.py` before running.
